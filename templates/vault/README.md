# Vault (private)

Data only: tasks, project metadata, captures. The dashboard and tooling live in the
kit repo. **Keep this repository private.** Git is the sync layer: commit and push
small changes straight to `main`, no branches.

| Path | Role |
|---|---|
| `TASKS.md` | Today / pointer list (anything not yet filed) |
| `tasks/<category>/TASKS.md` | One list per category (`CATEGORIES` in the kit's `.env`) |
| `tasks/<category>/<project>/TASKS.md` | One list per project |
| `memory/projects/<project>.md` | Project metadata: code repos, status, next action |
| `memory/me.md` | Your preferences for agents (optional) |
| `inbox/` | Quick captures; file them into a list, then move to `inbox/processed/` |
| `dashboard/` | Generated by the dashboard (cache; mostly git-ignored) |

Progress notes are NOT here: they live in the separate notes repo (same folder
names). See the kit's `AGENTS.md` for the formats.
