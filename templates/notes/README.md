# Progress notes (private)

Lab-diary style progress notes, one folder per project. **Keep this repository
private, and never copy these files into a code repository.**

```
<category>/<project>/<Note>.md        e.g. work/website/Progress.md
<category>/<project>/attachments/…    images used by that folder's notes
<category>/<Note>.md                  category-wide notes
PROJECTS.md                           folder ↔ project ↔ code repos (generated by the dashboard)
.notes/sync.sh                        commit + pull + push, conflict-safe
.notes/agent-setup-prompt.md          prompt that sets up a code workspace's progress/ link
```

Folder names match the vault's task lists (`tasks/<category>/<project>/`).

- Dated entries `## Mon D, YYYY`, **newest on top**.
- Images `![](attachments/<file>)`, math `$…$` / `$$…$$`.
- `*.conflict-YYYYMMDD-HHMMSS.md` = the other side of an edit conflict: merge it into
  the note by hand, then delete it.

Edit in the dashboard's Notes tab (it saves and syncs itself), or in a code workspace
through its `progress/` link, then run `.notes/sync.sh`.
